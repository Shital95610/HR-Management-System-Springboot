# HR Management System - Spring Boot Microservice
REST APIs for Employee Management using Spring Boot + Spring MVC + Spring Data JPA

## Tech Stack
- **Java 17** - Streams, Optional, Lambda
- **Spring Boot 3.3.2**
- **Spring MVC** - REST Controllers
- **Spring Data JPA** - Data access layer
- **H2 Database** - In-memory for quick demo
- **Maven** - Build & dependency management
- **Git** - Version control

## JD Skills Demonstrated
1. **Microservices architecture**: Layered design - Controller → Service → Repository
2. **Spring Core**: Dependency injection with @Autowired, @Service, @Repository
3. **Spring MVC**: REST APIs with @RestController, @GetMapping, @PostMapping
4. **Java-ALL**: Used Streams, Optional, Exception handling in business logic
